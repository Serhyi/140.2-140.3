# ThinCap 140

Офлайн-додаток для розрахунку різниць, які виникають при здійсненні операцій з борговими зобов'язаннями з нерезидентами: **п. 140.2–140.3 ст. 140 ПКУ** (редакція з 01.01.2021), рядки **3.1.1 / 3.2.1 Додатка РІ** до декларації з податку на прибуток.

Інструмент підтримує професійне судження аудитора, але не замінює його. Оформлено в корпоративному стилі ТОВ АФ «Алекс С. Аудит» (Brand Guide v2.2).

## Можливості

- **Тест «3,5 раза»** за реєстром боргових зобов'язань перед усіма нерезидентами (п. 140.1). Середні значення на початок і кінець періоду; окремо обробляється від'ємний власний капітал.
- **СП із винятками абз. 7–8 п. 140.2:** суми, скориговані за ст. 39, проценти іноземним банкам і МФО з державною гарантією, частка амортизації капіталізованих процентів.
- **Ліміт 30 % від (ООПП + ФВ + АВ)** за позицією ДПС. Якщо показник від'ємний, обмежується вся сума процентів.
- **Пул перенесення (п. 140.3)** зі щорічним зменшенням на 5 %, звіркою із залишками платника та розбивкою за роками виникнення (FIFO).
- **Періоди наростаючим підсумком:** I квартал, півріччя, 9 місяців, рік.
- **Контрольні процедури** зі статусами «Успішно», «Попередження», «Помилка».
- **Друк робочого документа** на бланку АСА з A4, QR-кодом, нумерацією сторінок і блоком підписів.
- **Експорт:** JSON (файл завдання), Excel (потрібна мережа для бібліотеки SheetJS), PDF через друк.

### Методологічні налаштування

| Параметр | За замовчуванням | Альтернатива |
|---|---|---|
| 3.2.1 в об'єкті оподаткування для ліміту | Не враховується (механізм консультації ДПС: залишок × 0,95 додається до процентів поточного року) | Буквальне прочитання абз. 3 п. 140.2; розв'язується аналітично: D = (0,3·(ООПП₀+ФВ+АВ) − СП) / 1,3 |
| 3.2.1, якщо тест «3,5 раза» не виконано | Дозволено в межах ліміту 30 % | Не нараховується |

## Збирання

Результат — один HTML-файл без зовнішніх залежностей. Шрифти, логотип, QR-код і дані прикладу вбудовуються під час збирання.

```bash
python3 build.py
```

Без параметрів скрипт збирає **демо-версію** у `dist/thincap-140.html`.

```bash
python3 build.py --case cases/<кейс>.case.json --out cases/<кейс>.html
```

Ця команда збирає версію з даними конкретного завдання.

### Дані клієнтів

Каталог `cases/` занесено в `.gitignore`. **Дані клієнтів у репозиторій не комітяться**. У репозиторії є лише вигаданий демо-кейс `src/demo.case.json`.

Формат файлу кейсу:

```json
{ "title": "…", "state": { "meta": {…}, "method": {…}, "history": […], "periods": {…} }, "notesHtml": "<h2>…</h2>…" }
```

Файл `state` має ту саму структуру, що й «Зберегти JSON» у додатку. Тобто збережений з додатку файл можна обгорнути у `{"state": …}` і зібрати з ним персональну версію.

## Структура

```
src/app.html          розмітка і стилі (Brand Guide v2.2, цифровий і гібридний канал)
src/app.js            доменна логіка, рендеринг, друк, експорт
src/demo.case.json    вигаданий демо-кейс
build.py              збирання в один файл
brand/assets/         логотип і QR-код ТОВ АФ «Алекс С. Аудит»
vendor/fonts/         Manrope, Playfair Display, JetBrains Mono (woff2, latin + cyrillic; SIL OFL 1.1, див. LICENSES/)
```
